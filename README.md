# Crawl

A personal, never-for-profit Dungeon Crawler Carl-style solo text RPG. An AI DM (OpenRouter free models) narrates; all dice, state, maps and loot live in code. One API call per turn.

- Run locally: `npm run serve`, open http://localhost:8080
- Test: `npm test`
- Deploy: GitHub Pages (root of main). On iPhone: Safari > Share > Add to Home Screen.
- Design: `docs/crawl-design-doc.md`, `docs/item-bank.md`
- Data: `data/*.json` (classes, achievements, items, floor-1)
